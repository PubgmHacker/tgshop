# Проверка магазина нейросетей · 11 сентября 2026

## Статус

Локальный кандидат на релиз. Изменения кода проверяются на сборках Next.js
15.5.24, PostgreSQL и Redis. Публикация и проверка реальных платежей не выполнялись.
Действующие адреса получены через Railway; бот — `aiaccessrage_bot`. В локальном
`.env` остались `example.com` и `your_shop_bot`. Railway показывает SUCCESS для
шести приложений на коммите `5e61867` от 5 сентября. Текущие исправления ещё
не опубликованы. Публичные HTTP-запросы к сервисам из этой среды завершились
по тайм-ауту; это не доказывает недоступность сервера для других клиентов.

## Что исправлено

- Mirasim присутствует в миграции каталога, seed, выдаче API, миниаппе,
  представлении каталога ботом и лендинге. Способ выдачи — оператором;
  интерфейс сообщает об этом до покупки. Демо-ключи и фиктивный владелец
  больше не создаются. Повторный seed сохраняет изменения оператора.
- Скидки рассчитываются одной функцией в целых центах. Покупка и пополнение
  ждут действительные настройки, наличие и актуальную цену. Недействительный
  промокод не отправляет пользователя дальше; недоступный товар и недостаточный
  баланс не позволяют оплатить. Ссылки оплаты принимают только HTTPS без логина
  и пароля в URL.
- Исправлены совместимость с асинхронными `params`, `searchParams`, `cookies`
  в Next.js 15, клиентская гидратация локали и представление ошибок авторизации,
  JSON и ограничения запросов. Невалидный JSON, prototype pollution, слишком
  большой запрос и rate limit проверены тестами настоящего Fastify-плагина.
- Вход в веб-админку ограничен атомарными счётчиками Redis. Ошибка Redis закрывает
  вход; текущая роль проверяется на сервере при каждом действии. Telegram Login
  больше не обходит включённую 2FA. Параметры поставщика скрыты от SUPPORT,
  не копируются в новые записи аудита и действительно очищаются при удалении
  содержимого редактора.
- Запросы выдачи поставщику разрешены только по HTTPS к публичным IP. Все DNS
  ответы проверяются, соединение закрепляется за проверенным адресом; редиректы
  запрещены. Размер ответа ограничен 256 KiB. Тайм-аут отменяет сетевой запрос.
  Повторные попытки передают один `Idempotency-Key` для заказа.
- Убраны секреты из URL-логирования, исправлена метка неизвестного маршрута
  в метриках. Next.js, Fastify, PostCSS и fast-uri обновлены; зафиксирован lockfile.
- Веб-админка адаптирована для телефона. Русские подписи форм, статусы, сообщения
  и переключатель темы согласованы. Навигация больше не содержит кнопку внутри
  ссылки. Есть переход к содержимому, видимый фокус и восстановление после ошибки.
  Показатель среднего чека больше не назван ARPU. Остатки склада представлены
  читаемыми строками вместо накладывающихся подписей графика.
- Лендинг показывает полный срок тарифа и не называет разовую покупку
  пожизненным доступом. Контент виден до JavaScript и при reduced motion.
  Убраны мерцание CTA, декоративные ореолы и дублирующаяся бегущая строка оплаты.
  Исправлены перенос длинного заголовка политики и ссылки служебных страниц.
- В CI и release включена admin-miniapp. Публичные параметры лендинга передаются
  на этапе Docker-сборки; переменные окружения учтены в задачах Turborepo.

товары, тарифы, склад, заказы, пользователи, промокоды, рассылки, настройки.
На проверенных страницах нет горизонтального переполнения документа и вложенных
интерактивных элементов `a button`. Проверен настоящий вход временного локального
владельца. Повторная проверка всех маршрутов не воспроизвела React hydration error.

без переполнения и без JavaScript errors; Escape закрывает мобильное меню.
Протокол: `/tmp/shop-ui-confirmation.log`. Временная учётная запись локального
аудита удалена после проверки.

Сохранённые снимки: [обзор админки](audit/2026-09-11/admin-mobile.png),
[главная лендинга](audit/2026-09-11/landing-mobile.png).

Лендинг: русская и английская главные страницы, условия, политика

В предыдущем проходе этой же работы проверены клиентский миниапп и админ-миниапп
на 320/390 px: основные вкладки, товар Mirasim, товар без наличия, оформление,

Протоколы: `/tmp/shop-ui-mini-09.log`, `/tmp/shop-ui-admin-09.log`,
`/tmp/shop-purchase-10.log`. Это локальная браузерная проверка, а не физический

Визуальная оценка: основные операции стали понятнее; формы и тексты согласованы,
ширина телефона поддерживается, фиктивные обещания удалены. Это проверка

и замеры на реальных мобильных устройствах не проводились.

## Что требуется перед публикацией

1. Использовать production-переменные Railway при итоговой публикации.
   Продакшен-бандл, собранный с `api.example.com`, отправлять пользователям нельзя.
2. Проверить историю миграций целевой базы. В старой локальной базе ранее были
   применены черновики двух ещё не опубликованных миграций: `20260905100000` и
   `20260905110000`. Их checksum отличается от нынешнего безопасного SQL.
   История базы не переписывалась. Полная актуальная история успешно применена
   к отдельной чистой базе. Не использовать `migrate reset` на рабочей базе.
3. Пройти тестовый платёж и ручную выдачу Mirasim в реальном Telegram с настройками
   выбранного платёжного провайдера; подтвердить webhook, уведомление оператора,
   повтор callback и возврат. Автоматические тесты не заменяют этот этап.
4. Поставщик EXTERNAL_API должен поддерживать идемпотентность по orderId/заголовку.
   Отмена HTTP-запроса не отменяет уже выполненную операцию на его стороне.
   Существующие записи аудита с прежними параметрами поставщиков автоматически
   не переписывались.
5. Docker-образы и итоговое развертывание проверяются release pipeline. Локально
   проверены Next.js production build и код сервисов; успешная публикация образов
   и здоровье внешнего сервера здесь не подтверждены.

В доступном тексте сессии нет тел исходных `API Error: 422`, на которых оборвался
предыдущий агент. Проверены актуальные ошибки приложения и тесты; утверждать,
что восстановлена каждая потерянная операция старого агента, нельзя.
